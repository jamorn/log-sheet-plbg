ผมจะอธิบายความสัมพันธ์ relation table ให้ฟังอย่างละเอียดนะครับ 
1.  BaggingLocations จะมี 2 main unit คือ "BaggingCode": "PL" และ "BaggingCode": "SA"
1.1 "BaggingCode": "PL" จะมีหน่วยงานย่อยคือ # UnitPLBG
1.2  แต่ละ unit ย่อยของ # UnitPLBG จะกำหนดค่า KPI ต่างกัน ตาม table #Kpi
1.3 การ query OEE ในแต่ละวันจะผูกด้วย KIP เพื่อให้การแสดงผลที่ chart ได้ถูกต้อง ในช่วงข้ามปี จะต้องถาม record ในแถวนั้นด้วยว่าคือปีอะไร จากนั้นเอาไปถามใน table Kpi ก็จะค่าออกมา ถ้าปีปัจจุบันหาไม่เจอ ก็ให้เอาปีล่าสุดมาแทน เพื่อไม่ให้ได้ค่า null 
2. จากข้อมูลใน json จะต้องเปลี่ยน data taype ใหม่ทั้งหมด
3. AI มีอะไรจะถามผมเพิ่มใหม่ครับ

# **สรุป Database Design สำหรับระบบ OEE (Final Version)**

## **Overview**
ระบบ OEE (Overall Equipment Effectiveness) สำหรับโรงงานอุตสาหกรรม ใช้เก็บข้อมูลประสิทธิภาพเครื่องจักรใน 3 มิติ: Availability, Performance, Quality

## **Core Tables (15 ตาราง)**

### **1. Master Data Tables (ข้อมูลหลัก)**
```sql
-- 1.1 Cost Center (ศูนย์ต้นทุน)
CREATE TABLE CostCenter (
    CostCenterCode VARCHAR(10) PRIMARY KEY,
    CostCenterName NVARCHAR(50) NOT NULL
);

-- 1.2 Production Unit (หน่วยผลิต)
CREATE TABLE UnitPLBG (
    UnitId INT PRIMARY KEY,
    UnitName NVARCHAR(50) NOT NULL,
    CostCenterCode VARCHAR(10) NOT NULL,
    CONSTRAINT FK_UnitPLBG_CostCenter FOREIGN KEY (CostCenterCode)
        REFERENCES CostCenter(CostCenterCode)
);

-- 1.3 เครื่องจักร (Machines)
CREATE TABLE Machines (
    MachineId INT PRIMARY KEY,
    MachineName VARCHAR(10) NOT NULL,
    MachineClass VARCHAR(5) NULL,
    MachineActive BIT NOT NULL,
    MachineLine VARCHAR(1) NULL,
    CostCenterCode VARCHAR(10) NOT NULL,
    UnitId INT NOT NULL,
    StandardRPM INT NOT NULL,           -- สำหรับคำนวณ Performance
    BagWeightKG DECIMAL(5, 2) NOT NULL, -- น้ำหนักถุงมาตรฐาน
    InstallationDate DATE NULL,
    LastMaintenanceDate DATE NULL,
    
    CONSTRAINT FK_Machines_CostCenter FOREIGN KEY (CostCenterCode)
        REFERENCES CostCenter(CostCenterCode),
    CONSTRAINT FK_Machines_UnitPLBG FOREIGN KEY (UnitId)
        REFERENCES UnitPLBG(UnitId)
);

-- 1.4 เป้าหมาย KPI
CREATE TABLE KpiTargets (
    Item INT PRIMARY KEY,
    [Year] INT NOT NULL,
    UnitId INT NOT NULL,
    Oee_Target DECIMAL(5, 2) NOT NULL,  -- เป้าหมาย OEE %
    Availability_Target DECIMAL(5, 2) NULL,
    Performance_Target DECIMAL(5, 2) NULL,
    Quality_Target DECIMAL(5, 2) NULL,
    
    CONSTRAINT FK_KpiTargets_UnitPLBG FOREIGN KEY (UnitId)
        REFERENCES UnitPLBG(UnitId)
);

-- 1.5 กะงาน (Shifts)
CREATE TABLE Shifts (
    ShiftID INT PRIMARY KEY,
    ShiftName VARCHAR(20) NOT NULL,
    StartTime TIME NOT NULL,
    EndTime TIME NOT NULL
);
```

### **2. Downtime & Loss Management**
```sql
-- 2.1 หมวดหมู่การหยุดงาน
CREATE TABLE DowntimeCategories (
    CategoryID INT PRIMARY KEY,
    CategoryNameTH NVARCHAR(50) NOT NULL,
    CategoryLevel INT NOT NULL           -- 10=Planned, 20=Unplanned/Speed, 30=Quality
);

-- 2.2 ประเภทปัญหา (เชื่อมโยงกับ Category)
CREATE TABLE OeeLossTypes (
    ProblemTypeID INT PRIMARY KEY,
    TypeNameTH NVARCHAR(100) NOT NULL,
    CategoryID INT NOT NULL,
    IsActive BIT NOT NULL DEFAULT 1,
    DisplayOrder INT NOT NULL,
    
    CONSTRAINT FK_OeeLossTypes_DCat FOREIGN KEY (CategoryID)
        REFERENCES DowntimeCategories(CategoryID)
);
```

### **3. Employee & User Management**
```sql
-- 3.1 พนักงาน (ใช้ Windows Authentication)
CREATE TABLE EmployeeDetails (
    WindowsLogin NVARCHAR(128) PRIMARY KEY,    -- "DOMAIN\username"
    DisplayName NVARCHAR(100) NOT NULL,
    Email NVARCHAR(100) NULL,
    EmployeeID VARCHAR(20) NULL,               -- รหัสพนักงานจาก HR
    DepartmentCode VARCHAR(10) NULL,           -- ลิงค์กับ CostCenter
    AccessLevel VARCHAR(20) NOT NULL CHECK (AccessLevel IN ('OPERATOR', 'SUPERVISOR', 'ADMIN')),
    IsAllowed BIT NOT NULL DEFAULT 0,          -- White-list system
    DefaultMachineID INT NULL,
    FirstLogin DATETIME NULL,
    LastLogin DATETIME NULL,
    LoginCount INT DEFAULT 0,
    
    CONSTRAINT FK_EmployeeDetails_Dept FOREIGN KEY (DepartmentCode) 
        REFERENCES CostCenter(CostCenterCode),
    CONSTRAINT FK_EmployeeDetails_Machine FOREIGN KEY (DefaultMachineID) 
        REFERENCES Machines(MachineId)
);

-- 3.2 ตำแหน่งบรรจุถุง
CREATE TABLE BaggingLocations (
    BaggingCode VARCHAR(10) PRIMARY KEY,
    BaggingName NVARCHAR(100) NOT NULL
);
```

### **4. Transaction Tables (Transactional Data)**
```sql
-- 4.1 บันทึกการผลิต (Transaction แม่)
CREATE TABLE ProductionRecords (
    ProductionRecordID INT IDENTITY(1,1) PRIMARY KEY,
    MachineId INT NOT NULL,
    ShiftID INT NOT NULL,
    ShiftDate DATE NOT NULL,               -- วันที่สรุปผล (สำคัญสำหรับกะดึก)
    SegmentStartDateTime DATETIME NOT NULL,
    SegmentEndDateTime DATETIME NOT NULL,
    BagOutActualMT DECIMAL(10, 3) NOT NULL, -- ผลผลิตจริง (Metric Ton)
    RecordStatus VARCHAR(20) NOT NULL DEFAULT 'OPEN',
    EnteredBy NVARCHAR(128) NULL,          -- Windows Login ของผู้บันทึก
    EnteredAt DATETIME DEFAULT GETDATE(),
    
    CONSTRAINT FK_PR_Machines FOREIGN KEY (MachineId)
        REFERENCES Machines(MachineId),
    CONSTRAINT FK_PR_Shifts FOREIGN KEY (ShiftID)
        REFERENCES Shifts(ShiftID),
    CONSTRAINT CHK_SegmentTime CHECK (SegmentEndDateTime > SegmentStartDateTime)
);

-- 4.2 บันทึกปัญหา/การหยุดงาน
CREATE TABLE ProblemRecords (
    ProblemRecordID INT IDENTITY(1,1) PRIMARY KEY,
    ProductionRecordID INT NOT NULL,
    ProblemTypeID INT NOT NULL,
    StopDateTime DATETIME NOT NULL,
    StartDateTime DATETIME NOT NULL,
    CalculatedDowntimeMin DECIMAL(5, 2) NOT NULL,
    IsMachineDowntime BIT NOT NULL DEFAULT 1,
    OperatorLogin NVARCHAR(128) NULL,      -- Windows Login
    MaintenanceLogin NVARCHAR(128) NULL,   -- ช่างซ่อม (ถ้ามี)
    
    CONSTRAINT FK_PRec_PR FOREIGN KEY (ProductionRecordID)
        REFERENCES ProductionRecords(ProductionRecordID),
    CONSTRAINT FK_PRec_OeePType FOREIGN KEY (ProblemTypeID) 
        REFERENCES OeeLossTypes(ProblemTypeID),
    CONSTRAINT FK_PRec_Operator FOREIGN KEY (OperatorLogin) 
        REFERENCES EmployeeDetails(WindowsLogin),
    CONSTRAINT CHK_DowntimeTime CHECK (StartDateTime > StopDateTime)
);

-- 4.3 รายละเอียด Lot & Quality Loss
CREATE TABLE LotCompletionDetails (
    LotDetailID INT IDENTITY(1,1) PRIMARY KEY,
    ProductionRecordID INT NOT NULL,
    WasteRejectBags INT NULL,              -- จำนวนถุงเสีย (สำหรับคำนวณ Quality)
    WasteRejectKG DECIMAL(10, 3) NULL,     -- น้ำหนักขยะ (กิโลกรัม)
    GoodBags INT NULL,                     -- จำนวนถุงดี
    TotalBags INT NULL,                    -- จำนวนถุงทั้งหมด
    
    CONSTRAINT FK_LCD_PR FOREIGN KEY (ProductionRecordID)
        REFERENCES ProductionRecords(ProductionRecordID)
);
```

### **5. Summary & Reporting Tables**
```sql
-- 5.1 สรุป OEE รายวัน
CREATE TABLE DailyProductionSummary (
    ShiftDate DATE NOT NULL,
    MachineID INT NOT NULL,
    UnitId INT NOT NULL,
    ShiftID INT NULL,
    Target_OEE_Pct DECIMAL(5, 2) NOT NULL,
    Availability_Pct DECIMAL(5, 2) NOT NULL,
    Performance_Pct DECIMAL(5, 2) NOT NULL,
    Quality_Pct DECIMAL(5, 2) NOT NULL,
    OEE_Percentage DECIMAL(5, 2) NOT NULL,
    OEE_TargetMet BIT NOT NULL,
    Top_Downtime_Reason NVARCHAR(255) NULL,
    SupervisorLogin NVARCHAR(128) NULL,    -- หัวหน้ากะ
    Supervisor_Review_Time DATETIME NULL,
    
    CONSTRAINT PK_DailySummary PRIMARY KEY (ShiftDate, MachineID),
    CONSTRAINT FK_DS_Machines FOREIGN KEY (MachineID)
        REFERENCES Machines(MachineId),
    CONSTRAINT FK_DS_UnitPLBG FOREIGN KEY (UnitId)
        REFERENCES UnitPLBG(UnitId),
    CONSTRAINT FK_DS_Shifts FOREIGN KEY (ShiftID)
        REFERENCES Shifts(ShiftID),
    CONSTRAINT FK_DS_Supervisor FOREIGN KEY (SupervisorLogin) 
        REFERENCES EmployeeDetails(WindowsLogin)
);

-- 5.2 หมายเหตุจากหัวหน้า
CREATE TABLE SupervisorRemarks (
    RemarkID INT IDENTITY(1,1) PRIMARY KEY,
    ShiftDate DATE NOT NULL,
    MachineID INT NOT NULL,
    RemarkOrder INT NOT NULL,
    RemarkText NVARCHAR(500) NOT NULL,
    RemarkType VARCHAR(20) NOT NULL DEFAULT 'Supervisor',
    CreatedByLogin NVARCHAR(128) NOT NULL, -- Windows Login
    CreatedAt DATETIME NOT NULL DEFAULT GETDATE(),
    
    CONSTRAINT FK_SR_DailySummary FOREIGN KEY (ShiftDate, MachineID)
        REFERENCES DailyProductionSummary(ShiftDate, MachineID),
    CONSTRAINT FK_SR_CreatedBy FOREIGN KEY (CreatedByLogin) 
        REFERENCES EmployeeDetails(WindowsLogin),
    CONSTRAINT UQ_SR_Order UNIQUE (ShiftDate, MachineID, RemarkOrder)
);
```

### **6. Audit & System Tables (เพิ่มใหม่)**
```sql

CREATE TABLE UserAuditLogs (

    Status VARCHAR(20) NOT NULL DEFAULT 'PENDING',
    ReviewedBy NVARCHAR(128) NULL,

-- 6.3 System Parameters (Configurable)
CREATE TABLE SystemParameters (
    ParamKey VARCHAR(50) PRIMARY KEY,
    ParamValue NVARCHAR(255) NOT NULL,
    ParamDescription NVARCHAR(200) NULL,
    ParamType VARCHAR(20) DEFAULT 'STRING', -- STRING, NUMBER, BOOLEAN
    LastUpdated DATETIME DEFAULT GETDATE(),
    UpdatedBy NVARCHAR(128) NULL
);
```

## **Indexes สำหรับ Performance**
```sql
-- Production Records
CREATE INDEX IX_ProductionRecords_Machine_Date 
ON ProductionRecords(MachineId, ShiftDate, ShiftID);

CREATE INDEX IX_ProductionRecords_Date_Status 
ON ProductionRecords(ShiftDate, RecordStatus);

-- Problem Records
CREATE INDEX IX_ProblemRecords_ProductionRecordID 
ON ProblemRecords(ProductionRecordID);

CREATE INDEX IX_ProblemRecords_DateTime 
ON ProblemRecords(StopDateTime, StartDateTime);

-- Daily Summary
CREATE INDEX IX_DailyProductionSummary_Date_Unit 
ON DailyProductionSummary(ShiftDate, UnitId);

CREATE INDEX IX_DailyProductionSummary_Machine_Date 
ON DailyProductionSummary(MachineID, ShiftDate);

-- Employee Details
CREATE INDEX IX_EmployeeDetails_EmployeeID 
ON EmployeeDetails(EmployeeID);

CREATE INDEX IX_EmployeeDetails_IsAllowed 
ON EmployeeDetails(IsAllowed) WHERE IsAllowed = 1;

CREATE INDEX IX_UserAuditLogs_WindowsLogin 
ON UserAuditLogs(WindowsLogin, ActionTime);

ON UserAuditLogs(ActionTime);
```

## **Key Design Decisions**

### 1. **Windows Authentication Integration**
- ใช้ `WindowsLogin` (DOMAIN\username) แทนการสร้าง users table
- `IsAllowed` สำหรับ white-list system (30 คนจาก 100 คน)
- ไม่ต้องจัดการ password ในระบบ

### 2. **Shift Date Handling**
- `ShiftDate` แยกจาก `DateTime` สำหรับกะดึก (ข้ามเที่ยงคืน)
- Business date อาจไม่ตรงกับ calendar date

### 3. **OEE Calculation Structure**
- Availability → จาก `ProblemRecords` (Downtime)
- Performance → จาก `StandardRPM` ใน Machines vs Actual
- Quality → จาก `WasteRejectBags` ใน `LotCompletionDetails`

### 4. **Audit Trail**
- `UserAuditLogs` บันทึกทุกการเข้าถึง
- `EnteredBy` ในทุก transaction table
- Timestamp และผู้กระทำบันทึกครบ

### 5. **Scalability Considerations**
- Indexes สำหรับ query ที่ใช้บ่อย
- แยกตาราง Transaction vs Summary
- รองรับการเพิ่ม Loss Types ได้ง่าย

## **สรุป Technical Highlights**

1. **Security**: Windows Authentication + White-list system
2. **Performance**: มี Indexes และ normalized structure
3. **Auditability**: มี audit trail ทุกการกระทำ
4. **Maintainability**: แยกตารางตามหน้าที่ชัดเจน
5. **Scalability**: รองรับการเพิ่มเครื่องจักรและพนักงาน
6. **Business Logic**: คำนวณ OEE ตามมาตรฐานสากล
7. **Real-world Ready**: จัดการกะดึก, multiple shifts, configurable parameters
